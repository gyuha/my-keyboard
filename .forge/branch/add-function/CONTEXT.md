# my-keyboard — 분할 키보드 CAD

한글 타이핑에 최적화한 자작 분할 키보드(split keyboard). 가운데 B키·한/영키·펑션 매핑을 추가한 `add-function` 레이아웃을 3D 프린팅용 케이스로 설계한다.

## Language

**상판 (switch plate)**:
스위치가 끼워지는 최상단 1.5mm 판. `left-switch.dxf` / `right-switch.dxf`의 외곽선 + 스위치 컷아웃으로 정의된다. 키 배치의 원천(source of truth).
_Avoid_: 플레이트(단독), 탑플레이트

**케이스 바디 (case body)**:
상판 아래에서 벽체를 이루는 가운데 부품. 스위치 다리·손배선·다이오드·컨트롤러를 담는 공간을 만들고, 상단 단(lip)으로 상판을 받치며 열간 인서트 보스를 갖는다.
_Avoid_: 하우징(모호), 프레임

**하판 (bottom plate)**:
케이스 바디를 아래에서 닫는 부품. M3 나사로 보스에 결합한다.
_Avoid_: 베이스, 바닥판

**스위치 컷아웃 (switch cutout)**:
상판에서 MX 스위치가 통과하는 구멍. DXF 원본은 13.9mm 정사각형 + 스위치 탑 제거용 노치. FDM 수축 보정을 위해 파라메트릭 오프셋으로 실모델 개구부를 ~14.0mm로 키운다. [[freecad-keyboard-case]]

**컷아웃 오프셋 (cutout offset)**:
DXF 컷아웃 외형을 유지한 채 개구부를 넓히는 파라미터. 프린터별로 튜닝해 스위치 물림을 맞춘다.

**웨지 틸트 (wedge tilt)**:
케이스를 뒤가 높은 쐐기꼴로 만들어 얻는 앞으로 6° 타이핑 각도. 상판은 이 각도로 기울고 하판은 책상에 평평하게 놓인다.

**반쪽 (half)**:
분할 키보드의 좌(left) 또는 우(right) 한 짝. 각 반쪽은 독립된 상판·바디·하판 3부품과 자체 RP2040 컨트롤러를 가지며, 둘은 TRRS 시리얼로 연결된다.
