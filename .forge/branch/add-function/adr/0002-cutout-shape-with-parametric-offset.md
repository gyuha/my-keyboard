# 스위치 컷아웃은 DXF 원형(13.9mm+노치)을 유지하고 파라메트릭 오프셋으로 확장한다

DXF 스위치 컷아웃은 13.9mm 정사각형에 스위치 탑 제거용 노치가 붙어 있다. Cherry MX 표준 개구부는 14.0mm이고, FDM은 구멍을 0.2~0.4mm 작게 뽑아 13.9mm 그대로는 스위치가 안 물리거나 상판이 갈라질 위험이 크다. DXF를 수정하거나 표준 14mm 사각으로 갈아끼우면 노치(무납땜 스위치 탑 분리 기능)를 잃으므로, **DXF 외형을 그대로 쓰되 컷아웃 와이어에 프린터별로 튜닝 가능한 오프셋을 적용**해 실모델 개구부를 기본 ~14.0mm로 키운다. DXF 파일 자체는 원천 입력으로 건드리지 않는다.

## Consequences

- `SWITCH_CUTOUT_TARGET`(기본 14.0mm) 변수로 목표 개구부를 지정하고, 오프셋 = (target − 13.9)/2 를 컷아웃 와이어에 바깥쪽으로 적용한다. 스위치가 빡빡하면 14.05~14.15로 올려 재출력한다.
- 노치를 포함한 복잡한 와이어에 오프셋을 적용하므로, FreeCAD `makeOffset2D`가 실패하는 코너가 있으면 해당 컷아웃만 폴백(중심 기준 스케일)으로 처리한다.
