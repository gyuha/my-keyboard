# run — 문서를 PCB 기준으로 다시 쓰기

## 슬라이스별 결과

- S1 핀 배치 표 재작성 — ✅ 계획대로. 행 수 6→5, 행 핀 `GP2~GP6`, 열 핀 `GP7~GP15`, 시리얼 `GP0`, 전원 `3V3`. "원천은 `pcb/split-keyboard.epro`, 손으로 고치지 말 것" 명시. ⚠ 계획에 없던 **`### 분할 링크` 절을 신설**했다 — 커넥터가 USB-C 인데 USB 가 아니라는 것, 3선만 쓴다는 것, full-duplex 가 성립하지 않는 이유, 그리고 같은 모양 포트 2개에 대한 경고를 표의 각주로 밀어 넣을 수 없었다.
- S2 손배선 자료 제거 — ✅ 계획대로. 배선도 이미지 2개, `스트레오 컨넥트 연결 핀` 절, kbfirmware 문구를 삭제(296자). git 이력에 남으므로 "구버전 기록"으로 접어두지 않았다.
- S3 부품 표 갱신 — ✅ 계획대로. 추가: 메인 PCB 2 · aux 보드 2 · USB-C 브레이크아웃 2 · USB-C 케이블 1 · 1×16 저상형 소켓/헤더 각 2. 변경: 스위치 72→73, 다이오드 72→**73 (1N4148WS SOD-323, 하면 실장)**, 자석 5x2→**8x2**, 나사 M3*10→**M3*12**(관통 스택 명시). 삭제: 3.5mm 스테레오 커넥터 · aux 케이블 · 전선(랩핑와이어).
- S4 매트릭스 표 생성기 — ✅ 계획대로. `tools/gen_matrix_table.py` 가 `gen_keylayout.py` 와 같은 마커 방식으로 README 를 갱신한다. 재실행 후 변화 없음(재현 가능).
- S5 조립 문서 갱신 — ✅ 계획대로 네 항목 전부. ⚠ 계획이 예상하지 못한 것 하나: FreeCAD 모델 설명이 **구 참조 부품("RP2040-Zero(노랑)와 3.5mm 잭(초록)")** 을 가리키고 있었다. 3of4 에서 그 참조 파트를 PCB/aux 보드 참조로 교체했으므로 설명도 함께 고쳤다 — 이것이 DoD 5 의 `3.5mm` 마지막 잔존 1건이었다.

## Plan vs actual

5개 슬라이스 전부 들어갔고 Non-goals(`.worktree/pcb` 배선도 미수입 / EasyEDA 이미지 export 안 함 / 구버전 기록으로 접어두지 않음)를 지켰다. 발산 2건은 모두 "문장을 넣을 자리가 표 안이 아니었다"는 종류다.

DoD 5 의 `3.5mm → 0` 검사가 부품 표 밖의 문장까지 잡아냈다. 계획이 검사 범위를 파일 전체로 잡은 것이 결과적으로 옳았다 — 부품 표 구간으로 좁혔다면 FreeCAD 모델 설명은 낡은 상태로 남았을 것이다.
