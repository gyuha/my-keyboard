# PC 에 꽂는 반쪽을 우측에서 좌측으로 바꾼다 (MASTER_LEFT)

PCB 의 두 aux 보드가 메인 PCB 에 대해 서로 다른 위치에 앉는다는 것이 파서로 확정됐다. 헤더 1번 패드가 후면 가장자리에서 좌측은 6.47mm, 우측은 24.12mm 안쪽이고(차이 17.65mm), 그 결과 aux 보드 후면 오버행이 **좌 +1.66mm / 우 −16.30mm** 다. 좌측은 RP2040-Zero 의 USB-C 끝면이 보드 후면과 0.01mm 차이로 일치해 커넥터가 케이스 뒷벽을 그대로 관통하지만, **우측 호스트 USB-C 는 뒷벽에서 16.3mm 안쪽에 갇힌다.** 기존 설정은 `MASTER_RIGHT` 였으므로 하필 PC 에 꽂는 포트가 닿지 않는 쪽이었다.

**`MASTER_LEFT` 로 바꾼다.** 좌측 호스트 USB-C 는 아무 형상 작업 없이 쓸 수 있고, 변경 비용은 `gkey/keymaps/default/config.h` 한 줄이다. 대가는 우측 모듈의 USB-C 가 플래싱 전용이 되고 그때 플레이트 조립체를 떼야 한다는 것 — 스위치가 PCB 에 납땜돼 있어(핫스왑이 아니다) 플레이트·PCB·스위치가 한 몸으로 빠지므로 나사 4개를 풀면 접근된다. 자주 하는 일이 아니다.

버린 대안 둘. **우측에 USB-C 연장 패널마운트**는 `MASTER_RIGHT` 를 지키지만 부품과 내부 배선을 늘리고, 애초에 지키려는 것이 "케이블이 우측으로 나온다"는 습관뿐이다. **우측 벽에 16mm 깊이 터널 개구부**는 일반 USB-C 플러그의 오버몰드가 들어가지 못할 가능성이 높아 성립을 신뢰할 수 없다.

## Consequences

- `BOOTMAGIC_ROW`/`COLUMN` (0,0 = 좌측 ESC)이 이제 마스터가 직접 폴링하는 자리가 된다 — `_RIGHT` 쌍(5,0 = 우측 `6`)도 슬레이브 부팅용으로 그대로 유효하다. config.h 의 관련 주석이 `MASTER_RIGHT` 를 전제하므로 정정이 필요하다.
- 케이스 후면 개구부가 좌우 비대칭이 된다: **좌측은 호스트 USB-C + 분할 링크 USB-C 두 개, 우측은 분할 링크 하나**. 분할 링크 브레이크아웃은 손배선 3가닥이라 위치가 자유롭기 때문에 우측도 뒷벽에 낼 수 있다.
- 이 결정은 사용자가 "알아서 끝까지 진행"을 위임한 상태에서 자동 구동 중 내려졌다. 되돌리려면 이 ADR 을 폐기하고 `MASTER_RIGHT` 로 되돌린 뒤 위 대안 (연장 패널마운트 / 터널 개구부) 중 하나를 케이스에 넣으면 된다.
