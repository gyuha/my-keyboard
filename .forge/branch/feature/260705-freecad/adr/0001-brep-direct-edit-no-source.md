# 소스 스크립트 부재 상태에서 keyboard-plate는 B-rep 직접 편집으로 수정한다

`keyboard-plate v9` 모델은 Fusion 세션 안에서 Python으로 파라메트릭 생성됐으나, 그 소스 코드가 프로젝트에도 Fusion 저장 스크립트(`list_scripts` 빈 목록)에도 남아있지 않고 세션 변수만 잔존한다. 파라메트릭 재생성 로직을 역설계하는 대신, 국소 수정은 기존 B-rep body를 Fusion API로 직접 잘라내고 재구성하는 방식으로 진행한다.

속도·안전성을 위해 재현성을 포기한 선택이다. 향후 수정도 손편집이 누적되므로, 형상이 안정되면 파라메트릭 생성 스크립트를 별도로 복원·저장(프로젝트 파일 또는 Fusion `save_script`)할 것을 권장한다.
