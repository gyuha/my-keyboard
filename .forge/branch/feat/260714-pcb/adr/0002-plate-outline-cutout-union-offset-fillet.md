# 상판 외곽은 컷아웃 합집합을 8mm 각진 확장 후 5R 필렛으로 생성한다

상판 외곽을 PCB 보드 외곽선이 아니라 키 배열에서 도출한다. 14mm 스위치 컷아웃 사각들의 합집합을 만들고, 가장자리를 기준으로 정확히 8mm 바깥으로 **각진(miter) 확장**한 뒤(이때 분리돼 있던 컷아웃들이 병합되어 하나의 연결 외곽이 됨), 모든 코너(볼록·오목)를 **5R로 필렛**한다.

## Considered Options

- **8mm 라운드 오프셋(코너 자동 R8)**: 구현은 가장 단순하나 코너가 R8이 되어 "라운드 5R" 요구와 불일치. 기각.
- **스위치 중심 convex hull + 오프셋**: 매끈하지만 스태거 컬럼 오면을 따라가지 않음. 기각.
- **PCB 보드 외곽선 사용**: "키배열+8mm" 요구와 상충. 기각.

## Consequences

- 8mm(가장자리 거리)와 5R(코너 반경)이 독립적으로 성립하도록 확장→필렛 2단계로 처리한다.
- 결과 외곽은 PCB 보드 외곽(146×103 등)보다 약 4mm 크게 오버행한다.
- 인접 코너 간 필렛이 간섭하면 해당 부위만 반경을 줄이는 폴백을 쓴다.
