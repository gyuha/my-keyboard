# 실행 기록 — PCB 기준 좌우 스위치 상판 재설계

## 산출물
- `freecad/create_switch_plate.py` — 새 파라메트릭 스크립트(DXF 파서 + 추출 + 빌드)
- `freecad/run_build.py` — freecadcmd 헤드리스 러너(build_all 호출)
- `freecad/left_switch_plate.stl` / `.step`, `freecad/right_switch_plate.stl` / `.step`
- `freecad/switch_plates.FCStd` (좌·우 상판 + 그 아래 PCB 보드 시각화 포함)

## 계획대로 된 것
- 좌·우 상판을 각 PCB DXF에서 독립 생성(미러 아님). 스위치 컷아웃 14.0mm.
- 접시머리 M3 상면 카운터싱크(Ø6.2/90°, 깊이 ~1.4mm), 관통 Ø3.4, 두께 1.5mm 평판.
- 좌·우 모두 단일 유효 솔리드, 두께 1.50mm 측정 확인.

## 발산(Divergences) — 계획과 크게 달라짐
1. **[높음] 스위치 위치 추출 방식 변경**: 계획은 Multi-Layer Ø4 중심홀 가정. 실제로는 Ø4 홀이 스위치의 절반만 검출돼(2점 bulge 호 문제) 신뢰 불가 → **Component-Shape-Layer의 16mm 스위치 바디 courtyard**로 전환(스위치당 1개, Top-Silkscreen과 교차검증). ADR-0001이 경고한 "PCB export 역추출의 취약성"이 실제로 발현됨.
2. **[중간] 좌우 비대칭 키 수 확정**: 좌 30키(5행×6열) / 우 43키(function 클러스터 포함). 계획서엔 수치 미기재.
3. **[높음] 외곽선 방식 변경(사용자 중도 지시)**: 계획/ADR-0002는 "14mm 컷아웃 합집합 → 8mm 각진 확장 → 코너 5R 필렛(유기적 형상)". 첫 렌더 확인 후 사용자가 **단순 둥근 사각형(키 컷아웃 bbox +8mm, 코너 R5)**으로 변경 요청. ADR-0002는 현재 산출물과 불일치 → 갱신 필요.
4. **[높음] 나사 구성 변경**: 계획은 "PCB Ø5 코너 4 + Ø3 중앙 모두 재사용". 실행 중 발견 — (a) 좌측 코너홀 4개 중 2개가 키+8mm 외곽선 밖(0.4·7.5mm), (b) 우측 PCB엔 코너홀 없음. 사용자 결정으로 **중앙 Ø3 홀 전부 제거, 코너 나사만** 사용. 코너 나사는 보드 bbox 모서리에서 3mm 안쪽으로 도출(좌측은 기존 PCB Ø5 홀과 정확히 일치, 우측은 대칭 배치). 결과 좌·우 각 4개.
5. **[낮음] 코너 보스 미적용**: 계획은 "코너홀 하면 국부 보스". 둥근 사각 외곽에서 코너 나사가 모서리에 가까워 Ø9 보스가 외곽 밖으로 돌출 → 보스 없이 평판 1.5mm에 카운터싱크(잔여 ~0.1mm, 빠듯하나 코너가 R5 라운드 재질 안에 완전히 들어옴 확인).
6. **[중간] 실행 환경 변경**: FreeCAD MCP(GUI) 연결이 세션 중 반복적으로 끊김("Connection refused") → **freecadcmd 헤드리스**로 빌드/export. 메모리의 "GUI 필요(색상 손실)" 경고는 기능성 상판 STL/STEP에는 무관하여 문제 없음. MCP는 시각 확인용으로만 사용.
7. **[중간] 저장소 외부 변경**: 세션 중 외부에서 HEAD가 483d061→84ea7f5("삭제")로 이동, switch.dxf·기존 FCStd·STL·구 스크립트 일괄 삭제(클린 슬레이트). PCB DXF 2개만 남음.

8. **[낮음] PCB 보드 시각화 추가(사용자 요청)**: Board-Outline을 두께 2mm 솔리드로 만들어 상판 아래에 배치(상판 바닥 ~ 보드 윗면 간격 `BOARD_GAP=5mm`, MX plate-mount 기준·조정 가능). 좌·우 `{name}_pcb_board` 객체로 FCStd에 포함. 3D 프린트 대상이 아니므로 STL/STEP 별도 export는 하지 않음. **보드 모퉁이는 R3 라운드**(실제 DXF 폴리라인의 bulge=-0.414 = 90° R3 호. 파서가 bulge를 안 읽어 처음엔 모퉁이가 잘려 보였으나, bbox+R3 둥근 사각형으로 재현 — `BOARD_CORNER_R=3.0`).
9. **[중간] PCB 코너 고정홀 표시(사용자 정정)**: 처음엔 Ø3 홀을 나사홀로 오분류했으나, 사용자 확인 결과 **Ø3 홀은 스태빌라이저 홀**이고 실제 필요한 건 **PCB 네 모퉁이의 원형 홀(하단 body 고정용)**임. 코너 홀을 지름이 아닌 **위치(보드 bbox 모퉁이 근접)** 로 검출해 보드에 관통, 스태빌라이저 홀은 제외. 좌=Ø5 코너 4개, 우=Ø3.55 코너 4개(지름은 좌우 다르나 위치 기준이라 모두 검출됨). 이 코너 위치는 상판 코너 나사 위치와 일치 → 상판→PCB→body가 코너에서 한 축으로 정렬.

## 검증(UAT)
- 수치: 두께 1.50, 컷아웃 수=스위치 수(좌 30/우 43), 코너 나사 4개 관통+상면 flush 카운터싱크(top_void/bot_solid 확인), 단일 유효 솔리드.
- 시각: FreeCAD MCP Top 뷰 렌더로 둥근 사각 외곽·코너 나사·중앙홀 제거·컷아웃 배열을 사용자와 함께 확인.
