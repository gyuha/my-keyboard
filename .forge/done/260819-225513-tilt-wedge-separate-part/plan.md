# 틸트 웨지를 별도 부품으로 분리해 케이스를 서포트 없이 출력

## 목표 / 비목표

- **목표**: 케이스 바디에 붙어 있던 틸트 웨지를 독립 부품으로 떼어내, 바디·웨지 모두 FDM 서포트 없이 출력되게 한다. 웨지의 6mm 인셋(옆에서 케이스가 들려 보이는 조형)과 안착 각도·높이는 그대로 유지한다.
- **비목표**:
  - `freecad/parametric_stl/split keyboard.3mf` 갱신 — 배치·서포트 설정은 슬라이서에서 사람이 한다. **실행 후에도 3mf 안에는 옛 형상이 남아 있다.**
  - 스위치 플레이트·팜레스트 형상 변경 (STL 재내보내기도 하지 않는다)
  - 틸트 각도 변경 — 지금 각도(약 4.32°)는 그대로 둔다
  - 자석 체결식 탈착 웨지, 미끄럼방지 패드 자리 추가

## 진실의 출처

- **용어집**: `틸트 웨지`, `결합면` — `.forge/CONTEXT.md`
- **관련 ADR**: `.forge/adr/260819-204944-tilt-wedge-as-separate-glued-part.md`
- **완료의 정의**: 좌·우 바디와 좌·우 틸트 웨지 STL 4개가 각자의 출력 자세에서 서포트 검사(베드 접촉을 제외한 45° 초과 하향면 면적 ≤ 60mm²)를 통과하고, README에 웨지 접착 절차가 반영된 상태.

## 확정 사항 (그릴링 결과)

| 항목 | 값 |
| --- | --- |
| 분리 방식 | 웨지를 독립 부품으로 출력해 바디 바닥에 **접착** |
| 웨지 앞 끝 | 두께 1.5mm 미만 구간(앞에서 약 21mm)을 **잘라낸다**. 안착 각도·높이는 불변 |
| 정렬 | 웨지 상단에 지름 **4.0mm** · 높이 **1.3mm** 핀 2개, 바디 바닥에 지름 **4.3mm**(+0.3, 자석 포켓 관례) · 깊이 **1.5mm** 홀 2개 |
| 핀 위치 | 웨지 상단면 폭 방향 양 끝에서 안쪽 15mm, 깊이 방향 중앙 |
| 출력 자세 | 바디는 바닥면을 베드에 대고 평평하게(기존 4.32° 기울임 폐기), 웨지는 경사면을 베드에 |
| 현재 측정치 | 바디 서포트 필요 면적 2,576mm² (측면 1,464 · 뒷면 894 · 기타 218) |

## 작업 슬라이스

- [ ] **S1. 서포트 검사기를 먼저 쓴다** — `freecad/verify_no_support.py`. STL 경로와 출력 자세(회전)를 받아, 베드 접촉면을 제외한 45° 초과 하향면 면적을 계산하고 기준치(60mm²) 초과 시 exit 1. `verify_magnet_pockets.py`의 출력·종료코드 관례를 따른다.
  - 완료 기준: 지금의 `left_keyboard_body.stl`을 현재 출력 자세(4.32° 기울임)로 검사하면 **실패(exit 1)하고 약 2,576mm²를 보고**한다.
- [ ] **S2. 웨지를 바디에서 분리한다** — `create_keyboard_parametric.py`의 `Body_Rest` 웨지를 바디에서 제거하고 `Left_Tilt_Wedge` / `Right_Tilt_Wedge` Body로 새로 만든다. 두께 1.5mm 미만인 앞쪽 구간은 잘라낸다. 뒤쪽 능선 R3 필렛은 웨지 쪽에 남는다. (depends: S1)
  - 완료 기준: 재생성한 문서에서 웨지 2개가 각각 유효한 단일 솔리드이고, 바운딩박스가 좌 **137.1 × 약 103.9 × 8.96mm** / 우 **184.7 × 약 103.9 × 8.96mm**, 최소 두께가 1.5mm 이상이다.
- [ ] **S3. 정렬 핀과 홀을 넣는다** — 웨지 상단에 핀 2개, 바디 바닥에 대응 홀 2개. 파라미터로 노출한다(`WedgeAlignPinDiameter` 4.0 / `WedgeAlignPinHeight` 1.3 / `WedgeAlignPinClearance` 0.3 / `WedgeAlignPinHoleDepth` 1.5 / `WedgeAlignPinInset` 15.0). (depends: S2)
  - 완료 기준: 핀 축과 홀 축의 XY 좌표가 0.01mm 이내로 일치하고, 홀이 바닥(두께 3mm)을 관통하지 않아 남는 살이 1.5mm다.
- [ ] **S4. GUI 모드로 재생성하고 STL을 내보낸다** — 색상 보존을 위해 반드시 GUI 모드. `left_keyboard_body.stl` / `right_keyboard_body.stl` 갱신 + `left_tilt_wedge.stl` / `right_tilt_wedge.stl` 신규. 플레이트·팜레스트는 건드리지 않는다. (depends: S3)
  - 완료 기준: `verify_no_support.py`가 STL 4개 전부에 대해 **통과(exit 0)**하고, 바디는 각각 60mm² 이하(자석 포켓·잭 구멍의 원형 브리지만 남는다)를 보고한다.
- [ ] **S5. README를 갱신한다** — 출력물이 6개에서 8개로 늘었다는 것, 웨지를 바디 바닥에 핀으로 맞춰 접착한다는 조립 단계, 그리고 3mf는 직접 갱신해야 한다는 사실. (depends: S4)
  - 완료 기준: README에 틸트 웨지 2개가 출력물로 등장하고, 접착·정렬 절차와 "슬라이서 프로젝트는 수동 갱신" 안내가 들어 있다.

## 검증 메모

- 서포트 판정은 눈이 아니라 면적으로 한다. 이번 그릴링에서 문제를 특정한 것도 육안이 아니라 이 계산이었다.
- 웨지를 뗀 바디를 평평하게 놓았을 때 남는 하향면은 이미 50.1mm²로 측정되어 있다. S4에서 이 값에서 크게 벗어나면(핀 홀 브리지 몫 이상) 형상이 의도와 다르게 바뀐 것이다.
