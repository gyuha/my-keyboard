# 자석 포켓 깊이를 접착제 부착 기준(2.2mm)으로 교정

## 목표 / 비목표

- **목표**: `MagnetHoleDepth`를 4.0 → 2.2mm로 내려, 접착제로 붙인 10×2mm 원형 자석이 결합면에서 0.1mm만 함몰되게 한다. 현재 값은 "2mm 양면테이프 + 2mm 자석" 가정으로 잡힌 것이라, 접착제(≈0.1mm)로 바꾸면 자석이 약 1.9mm 함몰되고 마주 보는 자석 사이 공극이 약 3.8mm가 되어 사실상 붙지 않는다. 즉 이것은 새 기능이 아니라 **깨진 값의 교정**이다.
- **비목표**:
  - `MagnetHoleClearance`(0.3) · `MagnetDiameter`(10.0) 변경 — 유지. 스케치 원 8개가 r=5.15로 구워져 있어 지름 변경은 스크립트 전진 재생성을 요구하고, 반경 여유 0.15mm는 접착제 부착에 정상 사양이다. 출력물이 빡빡하면 사포·리머로 사후 확장한다(넓게 나오면 되돌릴 수 없음).
  - `MagnetBossThickness`(3.0) 변경 — 유지. 포켓이 2.2mm면 벽(3.0)만으로도 관통하지 않지만, 보강 패드를 남겨 잠여 3.8mm를 확보한다. 잔여 0.8mm는 0.4mm 노즐에서 압출선 2개 수준이라 팜레스트를 당길 때 깨질 위험이 있다.
  - 지름의 파라메트릭화(스케치 원에 반지름 제약 + 표현식 바인딩) — 이번 요구와 무관.
  - 스크립트 전진 재생성 — 하지 않는다. 4개 포켓 전부 `Parameters.MagnetHoleDepth` 표현식에 묶여 있어 스프레드시트 셀 1개로 반영된다.
  - `*_switch_plate.stl` 2개 재내보내기 — 자석 포켓은 팜레스트·바디에만 있어 변하지 않는다.
  - 실제 시험 출력 · 자석 부착 후 인력 실측 — 별도 과제.
  - 커밋 / 푸시 / PR — 이 계획에 넣지 않았다. 필요하면 별도로 지시한다.
  - ADR 작성 — 게이트 미통과(되돌리기 비용이 파라미터 한 줄). 근거는 `PARAMS` 주석에 남긴다.

## 진리의 원천

- **용어**: `자석 포켓`, `결합면` — `.forge/CONTEXT.md`
- **관련 ADR**: 없음
- **확정된 수치 근거**:
  - 자석 10.0mm 지름 × 2.0mm 두께, 접착제 부착(접착층 0.1mm 가정)
  - 포켓 깊이 2.2 = 접착제 0.1 + 자석 2.0 + 함몰 0.1
  - 결합면끼리 밀착 시 자석 간 공극 = 0.1 × 2 = 0.2mm → 인력 밀착 대비 약 90%
  - 얕게 프린트되면 정확히 플러시가 되므로, 오차가 **돌출이 아닌 방향**으로 실패한다
  - 자석 뒷벽 잠여 = 바디벽 3.0 + 보강 패드 3.0 − 포켓 2.2 = **3.8mm**
- **완료 정의**: 헤드레스 측정 스크립트가 (1) 스프레드시트 B34 == 2.2, (2) 4개 `*_Magnet_Pockets`의 `Length` == 2.2mm, (3) 결합면에서 포켓 밑면까지의 **실측 거리** == 2.2mm, (4) 바디 쪽 포켓 밑면에서 보강 패드 안쪽 면까지 == 3.8mm를 전부 통과하고, 팜레스트·바디 STL 4개가 재생성되어 있다.

## 작업 조각

- [ ] **S1. 헤드레스 검증 스크립트 작성 — 현재 모델에서 FAIL하는 것을 먼저 확인**
  `freecad/verify_magnet_pockets.py`를 만든다. `/Applications/FreeCAD.app/Contents/Resources/bin/freecadcmd`로 `keyboard_parametric.FCStd`를 열어 위 완료 정의의 4개 항목을 검사하고, 실패 항목을 사람이 읽을 수 있게 출력한 뒤 exit code 1로 끝낸다.
  실측(항목 3·4)은 속성값을 믿지 말고 솔리드에서 직접 잰다: 각 포켓의 원통면 축 방향을 구하고, 반지름 5.15의 평면 원형 면(포켓 밑면)과 결합면 사이 거리를 축에 투영해 계산한다. 팜레스트 쪽 포켓은 **기울어진** 후면에 수직으로 뚫려 있으므로 Y축이 아닌 면 법선으로 재야 한다.
  — 완료 기준: 지금 실행하면 4개 포켓이 4.0mm로 잡혀 **명시적으로 FAIL**을 출력하고 exit code가 1이다. (통과해버리면 스크립트가 자재를 못 잡는 것이므로 스크립트를 고친다.)

- [ ] **S2. 스크립트 PARAMS와 주석 교정** (depends: S1)
  `freecad/create_keyboard_parametric.py:54-58`에서 `"MagnetHoleDepth": 4.0` → `2.2`. 위 주석 3줄은 지금 "rides on a 2mm double-sided sticker"라고 4.0의 근거를 명시하고 있어 그대로 두면 거짓이 된다 — 접착제 기준(접착층 0.1 + 자석 2.0 + 함몰 0.1, 오차가 돌출 아닌 플러시 방향으로 실패)으로 다시 쓴다. 주변 코드 스타일(영문 주석)에 맞춘다.
  — 완료 기준: `PARAMS["MagnetHoleDepth"] == 2.2`이고, 주석에서 양면테이프 언급이 사라지고 접착제 기준 수치 근거가 서술되어 있다.

- [ ] **S3. FCStd에 반영 — GUI(MCP)에서 셀 수정 · recompute · 저장** (depends: S2)
  freecad MCP로 GUI에서 `Parameters` 시트의 `B34`(alias `MagnetHoleDepth`)를 4 → 2.2로 바꾸고 `recompute()` 후 저장한다.
  **헤드레스(freecadcmd)로 저장하지 않는다** — GuiDocument가 날아가 파트 색상이 사라진다. 조회·측정만 헤드레스로 한다.
  — 완료 기준: S1 스크립트가 전부 PASS. 추가로 6개 파트의 `ViewObject.ShapeColor`가 변경 전과 동일하다(변경 전 값을 먼저 기록해 비교).

- [ ] **S4. 영향 받는 STL 4개 재내보내기** (depends: S3)
  `freecad/parametric_stl/`의 `left_palm_rest.stl`, `right_palm_rest.stl`, `left_keyboard_body.stl`, `right_keyboard_body.stl`.
  — 완료 기준: 위 4개 파일의 mtime이 갱신되고, `left_switch_plate.stl` · `right_switch_plate.stl` 2개는 mtime이 변하지 않는다.

## 조립 시 주의 (모델 밖 사항, 기록용)

- 접착제(특히 순간접착제)는 되돌릴 수 없다. 붙이기 전에 마주 보는 두 자석의 극성이 **끌어당기는지** 반드시 확인한다. 4개소 모두.
- 포켓은 거의 수직인 면에 뚫려 있어 출력 시 원의 상부 아치가 무지지 구간이다. 처짐으로 개구부가 좁아지면 사포·리머로 넓힌다.
