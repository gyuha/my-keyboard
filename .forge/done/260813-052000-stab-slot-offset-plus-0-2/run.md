# 실행 기록 — 스테빌라이저 슬롯 상향 (2회차: +0.4)

> 1회차(`+0.2`)는 실물 검증에서 `failed`였다. 간섭이 크게 줄었으나 여전히 약간 부족하다는
> 사용자 확인에 따라, 같은 절차로 값만 올려 재실행했다. 아래는 2회차 기록이다.

## 작업 단위 결과
- S1 파라미터·독스트링 수정 — ⚠ 계획과 다른 값: 계획은 `+0.2`지만 1회차 UAT 실패를 받아 `+0.4`로 실행했다. 독스트링에 "+0.2는 출력했더니 여전히 살짝 걸렸다"는 경위와 새 기준(스위치 중심 대비 `-0.25 mm`)을 반영했다.
- S2 GUI 재생성 및 플레이트 STL 내보내기 — ✅ 계획대로: `keyboard_parametric.FCStd` 재생성, 좌·우 스위치 플레이트 STL 재내보내기(03:10). 바디·팜레스트 STL 4개는 미변경.
- S3 좌표 대조 — ✅ 계획대로(기준값만 정정): 10개 슬롯 전부 `dX ±11.899~11.901`, `dY -0.250`, 폭 `3.299~3.301`, 세로 `14.100`.
- S4 실물 검증 — ✅ 통과(조건 추가): `+0.4` 출력·조립 결과 2u 키가 정상 동작한다. 단 **스위치를 180도 돌려 장착해야** 한다는 조건이 붙었다.

## 계획과 실제 차이
- **가장 큰 차이 — 실행한 오프셋이 계획과 다르다.** `plan.md`는 `+0.2`로 되어 있고 실제로는 `+0.4`를 적용했다. 1회차 실물 검증에서 "많이 좋아졌지만 약간 부족"이라는 결과가 나와, 사용자가 값을 올려 재생성하도록 지시했다. 봉인 전에 계획을 `+0.4`로 재그릴링해 맞추거나, 이 차이를 문서화된 차이로 인정하고 봉인할지 결정해야 한다.
- **1회차에서 계획의 S3 기준값 오류를 발견했다.** 슬롯 세로 길이를 `14.20 mm`로 적었으나 그건 원본 DXF 값(14.201)이고 모델은 `StabCutoutHeight = 14.1`로 줄인다. 2회차에서는 `14.100`을 기준으로 검증했고, 같은 혼동이 재발하지 않도록 독스트링에 DXF 값과 모델 값을 나란히 적었다.
- **최종 해결은 오프셋이 아니라 스위치 방향이었다.** `+0.4`로 출력한 뒤에도 키캡과 철사가 부딪혔고, 테스트 쿠폰(`+0.4 / +0.6 / +0.8`)으로 재보니 `+0.4`는 키캡, `+0.6`은 스위치에 걸려 쓸 수 있는 폭이 0.2 mm뿐이었다. 출력 오차와 같은 자릿수라 어떤 오프셋도 재현되지 않는다. 사용자가 2u 키의 스위치를 180도 돌려 꽂자 `+0.4`에서 정상 동작했다. 즉 이 작업이 바꾼 오프셋 값 자체는 맞았지만, 성공의 결정적 조건은 모델 밖(조립 방향)에 있었다. ADR `260812-224138`에 개정으로 기록했다.
- **테스트 쿠폰을 별도 산출물로 만들었다.** 전체 플레이트를 매번 몇 시간씩 출력하는 대신, 스위치홀 1개 + 스테빌 슬롯 2개만 남긴 2 mm 타일을 오프셋별로 한 판에 뽑는 `freecad/create_stab_test_coupon.py`를 추가했다. 계획에 없던 작업이지만 이후 판단을 전부 이 쿠폰으로 했다.
- **상한값이 여전히 미측정이다.** 과거 `+1.0`에서 스테빌과 스위치가 충돌했지만 그건 철사가 플레이트 위에 갇혀 있던 시절의 데이터라 지금은 무효다. 철사가 아래로 내려간 조건에서의 상한은 아무도 모른다. `+0.4`가 또 부족하면 다음 값을 정할 근거가 없으므로, 그때는 값을 하나씩 올리는 대신 테스트 쿠폰(슬롯 1개 + 스위치홀만 남긴 타일을 여러 오프셋으로 한 판에 출력)을 권한다.
- Dynamic Workflow 없이 직접 실행했다(1회차와 동일, fg-run 비용 예외 조항).

## 자동 검증
- `StabCutoutYOffset == 0.4`
- FCStd 상면 실측 — 좌 4개·우 6개 전부 `dY -0.250`, `dX ±11.900`, 폭 `3.299~3.301`, 세로 `14.100`
- 내보낸 STL 독립 검증 — 좌 신규 모서리 `Y 21.709/35.809` 존재·이전 `21.509/35.609` 부재, 우 신규 `Y 2.659/16.759` 존재·이전 `2.459/16.559` 부재
- 변경 파일: `create_keyboard_parametric.py`, `keyboard_parametric.FCStd`, `parametric_stl/left_switch_plate.stl`(298,084 B), `parametric_stl/right_switch_plate.stl`(315,684 B). 바디·팜레스트 STL 미변경.
