# 실행 기록 — 케이스 외곽을 PCB에 밀착시키고 벽을 계단 벽으로 바꾸기

직접 실행(워크플로우 없음). 생성기 한 파일 + 검사 스크립트 하나 + GUI 재생성이라 단일 에이전트가 더 싸다고 판단.

## 조각별 결과
- S1 `compute_layout()` 외곽을 `pcb_rect` 기준으로, `OuterMargin`·`CornerRadius` 제거, `corner_radius` = PCB r + 0.3 + 1.2, `Body_Pcb_Ring_Pocket`(z 0 → −2.6) 추가, 포트 오프셋 보정 — ⚠ 앞변은 계획과 다름: `PcbRingThicknessFront` 3.0(링 없는 일반 벽, 외곽 = PCB + 3.3), 자석 보강 블록 높이를 −2.6에서 자름, `ModuleInboardOffsetWired`는 보정 불가(9.30 유지, 벽을 따라 3.42 이동)
- S2 `freecad/verify_pcb_fit.py` 신설 — ⚠ 계획의 (a)~(e)에 더해 (f) 바디∩PCB = 0, (g) 앞 자석 ∩ PCB = 0 추가, (e)는 XY 겹침이 아니라 높이 기준으로 변경, (c) 앞변 제외. 재생성 전 모델에서 a·b·c 전부 FAIL 확인
- S3 GUI 재생성 2회(1회차에서 자석 간섭 발견 → 수정 후 2회차) + STL 8개 — ✅ 8파트 모두 valid·단일 솔리드
- S4 README 치수표 + 계단 벽 설명 + 스택 −2.6 줄 — ✅

## 계획 대비 어긋남
1. **앞 자석 간섭 (계획이 놓침).** 1차 재생성 후 PCB 참조∩바디 = 78.24mm³가 나왔다. 원인은 두 가지였다. ① 자석 보강 블록(바닥~z 0)이 PCB 밑으로 1.2~1.5mm 들어갔다. ② 자석 포켓(⌀10.3, 중심 −6.2, 윗부분 −1.05)이 1.2mm 링을 뚫어 자석이 PCB와 4.68mm³씩 겹쳤다. 그릴링에서 "자석 포켓 2.2가 3.0 벽에 들어간다"는 것만 보고 포켓 **높이**가 PCB 하면 위로 올라온다는 걸 확인하지 않았다. 사용자에게 물어 앞변만 3.0 벽을 유지하기로 결정했다(ADR 예외 항목 추가). 그 결과 깊이는 계획의 106.35가 아니라 108.15가 됐다.
2. **좌측 유선 모듈은 PCB 기준 위치를 유지할 수 없었다.** 이 모듈은 옛 틈(PCB 가장자리 바깥 1.92)까지 차지하고 있어서, 새 벽(PCB 안쪽 1.5)과 물리적으로 겹친다. 오프셋을 그대로 두어 벽을 따라 3.42 안쪽으로 이동했다. y는 보정해서 유지했다. 이 모듈은 PCB 아래(상단 −4.9)에 있고 16핀 헤더는 패드만 있어서(전선 납땜) 간섭은 없다고 추론했다.
3. **틸트 각도 4.99° → 5.28°.** `rest_tilt()`가 바디 깊이에서 유도되므로(뒤 높이 고정, 깊이 113.95 → 108.15) 각도가 0.29° 커졌다. 계획에 없던 파급이지만 그대로 두었다.
4. 호스트 모듈은 이미 재생성 전에도 다이오드 D30 아래에 있었다(D30 하단 −3.7, 모듈 상단 −4.9, 1.2mm 여유). 앞으로 3.43mm 이동한 뒤에도 그 아래 있는 부품은 D30뿐이다.
5. 앞변을 뺀 세 변의 PCB 받침 턱은 포트 자리(뒷벽 1.0mm 박막) 폭만큼 끊긴다. 포트 자리 절삭이 −1.7까지 올라오기 때문이다.

## 실행 후 수정 — 틈 0.3 → 0.5 (2026-10-26, 사용자 요청)
사용자가 "PCB와 바디가 너무 딱 맞아 끼우면 잘 빠지지 않는다"고 해서 `PcbSeatClearance`를 0.5로 넓혔다. 링 1.2·벽 3.0은 유지했다. 포트·모듈 오프셋은 이동량 3.22에 맞게 다시 보정했다(14.61 / 32.66 / 14.78). `verify_pcb_fit.py`의 `SEAT_GAP`도 0.5로 바꿨다.
- 외곽: 좌 149.61 × 108.55, 우 202.00 × 108.55. PCB 밑 턱은 1.3, 앞쪽 보강 블록은 PCB 밑으로 1.0 들어간다.
- 재검증: verify_pcb_fit 전 항목 PASS(포트 PCB 기준 ±0.01) · no_support 4파트 PASS(bridged 43.7/52.4) · magnet 22 PASS · port_mounts 1·2·3·8 PASS · selftest 0 · PCB/플레이트∩바디 0. 틸트 5.28° → 5.26°.
- 교훈: 끼워 맞춤 틈은 FDM 출력에서 0.3이면 빡빡하다는 실사용 피드백이 나왔다.
