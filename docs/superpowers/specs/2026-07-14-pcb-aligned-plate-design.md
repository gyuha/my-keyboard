# PCB 정합 5줄 케이스 재생성 설계

- 날짜: 2026-07-14
- 대상: `freecad/create_keyboard_plates.py` (파라메트릭 생성 스크립트)
- 입력: `freecad/left-pcb.dxf`, `freecad/right-pcb.dxf` (EasyEDA 보드 DXF)
- 산출물: `freecad/keyboard_switch_plates.FCStd` 및 STL 재생성

## 1. 목표

기존 스위치 플레이트/케이스를, 새로 설계한 PCB(`*-pcb.dxf`)에 정합하도록 재생성한다.
- 플레이트·바디 외곽을 **PCB 외곽선과 동일**하게 만든다.
- 실제 PCB 레이아웃(하단 5줄)에 맞춰 **최상단 함수열을 제거**한다.
- PCB를 3D 모델에 **참조 솔리드 + 케이스 안착 턱**으로 부착한다.
- 4개 M3 카운터싱크 나사 방식과 스테빌라이저 릴리프를 **유지**한다.

## 2. 조사로 확정된 사실

| 항목 | 왼쪽 | 오른쪽 | 근거/신뢰도 |
|---|---|---|---|
| 스위치 플레이트 스위치 수 | 37개(6줄) | 51개(6줄) | 스위치 DXF 컷아웃 분석 [높음] |
| PCB 스위치 수(다이오드) | 30개 | 43개 | PCB TEXT `D*` 개수 [높음] |
| 최상단 줄(Y≈110) | 7개 | 9개 | 다른 줄과 24mm 간격(그 외 19mm) [높음] |
| PCB 외곽선 | 146.2×103.3 | 198.6×103.3 | `Board-Outline-Layer` 폐곡선(12정점, 4모서리 90° 호) [높음] |
| 좌표계 정합 | 동일 | 동일 | PCB 패드가 하단 5줄 컷아웃 안에 정확히 안착함(오버레이 확인) [높음] |
| PCB 마운팅 홀 | dia3.55 1개뿐 | 없음 | `Hole-Layer` 반경 히스토그램 [높음] |

핵심 결론:
- 두 DXF는 **동일 로컬 좌표계**를 공유한다. 하단 5줄만 남기면 PCB 스위치 풋프린트와 완벽히 정렬된다.
- 최상단 줄은 PCB에 존재하지 않는다(패드·다이오드 없음). 제거 시 스위치 수가 PCB와 일치(37−7=30).
- PCB에는 4-나사 마운팅 홀이 없다 → 나사는 **플레이트→바디(SPREDSERT 인서트)** 를 고정하는 기존 방식이 맞다. PCB는 케이스 턱 + 스위치 핀 납땜으로 고정된다.

## 3. 확정된 결정

1. **PCB 기준 5줄로 재생성** — 최상단 줄 제거. (키 7/8~9개 감소, 케이스 Y 약 27mm 단축)
2. **플레이트 외곽 = PCB 외곽선** — 기존 "컷아웃 bbox + 8mm 사각형" 폐기.
3. **바디 외곽도 PCB 외곽선을 따름** — 플레이트와 가장자리 일치.
4. **PCB 부착 = 참조 솔리드(1.6mm) + 안착 턱**.
5. **PCB 안착 높이 = 플레이트 상면에서 5.0mm(MX 표준) 기본값, 파라미터화**.
6. 나사홀(4× M3 카운터싱크)·스테빌라이저 포켓 로직 유지.

## 4. 아키텍처 (스크립트 변경)

생성 파이프라인은 유지하고, 외곽선 소스와 컷아웃 필터만 교체한다.

```
PCB DXF(Board-Outline-Layer) ──▶ read_pcb_outline() ──▶ Part.Wire(호 포함)
                                                              │
스위치 DXF(LINE 루프) ──▶ dxf_line_loops() ──▶ 컷아웃 ──▶ PCB 외곽 내부 필터(5줄만)
                                                              │
              ┌───────────────────────────────────────────────┤
              ▼                    ▼                    ▼       ▼
        build_plate()       build_body()       build_pcb_ref()  (팜레스트/틸트 유지)
     외곽=PCB wire        외곽=PCB wire        외곽=PCB wire×1.6t
     +5줄 컷아웃          +캐비티(내측 offset)  +안착 턱(내측 lip)
     +4 나사홀            +보스/USB/TRS/RP2040
     +스테빌라이저 포켓
```

### 4.1 신규 `read_pcb_outline(path)`
- `Board-Outline-Layer`의 단일 닫힌 LWPOLYLINE을 파싱.
- 정점 + bulge(code 42)를 읽어 bulge≠0 구간은 `Part.Arc`(호), 나머지는 `Part.LineSegment`로 `Part.Wire` 생성. (bulge=tan(θ/4); 원호 중점 = 현 중점 + b·(현길이/2)·수직단위벡터)
- 반환: 로컬 좌표계 기준 폐 Wire. (기존 `dxf_line_loops`는 LINE 전용이라 신규 함수 필요)

### 4.2 `build_plate` 수정
- `outline = Part.Face(pcb_wire).extrude(0,0,PLATE_THICKNESS)` (bbox 사각형 대신 PCB Wire).
- 컷아웃 필터: **각 컷아웃 중심이 PCB 외곽 Face 내부인 것만 유지** → 최상단 줄이 자연스럽게 제외됨(임계 Y 하드코딩 대신 기하학적 판정).
- 나사 위치: PCB 외곽 bbox 네 모서리에서 `SCREW_CORNER_OFFSET` 인셋. M3 사양 동일.
- 스테빌라이저 포켓: 남은 컷아웃에 대해 기존 로직 그대로.

### 4.3 `build_body` 수정
- 외곽: `pcb_wire`를 `-BODY_HEIGHT`에서 위로 압출.
- 캐비티: `pcb_wire.makeOffset2D(-BODY_WALL_THICKNESS)` 압출로 절삭. (offset 실패 시 PCB bbox 라운드 사각형으로 폴백)
- 보스·USB-C·TRS 잭·RP2040 안착부: 새 레이아웃 bbox(`x_min/x_max/y_min/y_max`) 기준으로 자동 재배치. 후면(y_max) 부착 피처는 새 후면으로 이동.
- **PCB 안착 턱(lip)**: 바디 벽 내측 상단에 PCB 하면 높이까지의 단(shelf). PCB 외곽 offset −`PCB_LEDGE_WIDTH`(기본 1.5mm) 링을, PCB 하면 Z 아래로 벽에 융합. PCB는 `PCB_SEAT_CLEARANCE`(기본 0.3mm) 여유로 안착.

### 4.4 신규 `build_pcb_reference`
- PCB 외곽 Face를 1.6mm 두께로 압출. 색상/표시 ON.
- 배치 Z: 아래 조립 스택 참고.

## 5. 조립 스택 (Z 좌표, 로컬)

플레이트는 z=0(하면)~+4(상면), 바디는 z=−18~0. PCB는 플레이트 상면(+4)에서 `MX_PLATE_TO_PCB`(=5.0mm) 아래.

```
z = +4.0  ── 플레이트 상면 (스위치 클립)
z =  0.0  ── 플레이트 하면 / 바디 상단 rim
z = −1.0  ── PCB 상면  (= +4 − 5.0)
z = −2.6  ── PCB 하면  (1.6mm) / 안착 턱 상면
z = −15.0 ── 캐비티 바닥
z = −18.0 ── 바디 바닥
```

주의: 표준 5mm는 1.5mm 플레이트 기준값이다. 본 설계의 플레이트는 4mm라 PCB 상면이 플레이트 하면보다 1mm 아래에 위치한다. 실제 스위치 스택과 다를 수 있어 `MX_PLATE_TO_PCB`를 파라미터로 노출하고, 실물 측정 후 조정한다. [낮음]

## 6. 파급효과

- **STL 6종 전부 재생성** — 현재 출력물과 다른(짧은) 케이스가 된다.
- 팜레스트·틸트받침은 새 레이아웃 기준으로 축소/이동한다(로직 변경 없음, 입력만 변경).
- **펌웨어/키맵**: 물리 키 수가 줄어든다(왼쪽 −7, 오른쪽 −8~9). QMK 키맵은 본 작업 범위 밖이나 별도 갱신 필요. [중간]
- `create_techdraw_sheets.py`(TechDraw)는 형상 변경에 영향받으나 본 작업 범위 밖.

## 7. 리스크와 대응

| 리스크 | 신뢰도 | 대응 |
|---|---|---|
| `makeOffset2D`가 호 포함 Wire에서 실패 | 중간 | 캐비티를 PCB bbox 라운드 사각형으로 폴백 |
| bulge→호 변환 오차 | 낮음 | 변환 후 Wire 닫힘/면 생성 검증, 안 되면 현(chord) 근사 |
| PCB 안착 높이 5mm가 실물과 불일치 | 낮음 | 파라미터화, 실물 측정 후 재생성 |
| 스크립트를 freecadcmd로 돌리면 색상 소실 | 높음 | FreeCAD MCP(GUI)에서 재생성 (메모리 노트) |

## 8. 검증 기준

1. `read_pcb_outline`이 좌/우 PCB에서 닫힌 Wire를 만들고 `Part.Face` 생성 성공. bbox가 146.2×103.3 / 198.6×103.3과 일치.
2. 재생성된 플레이트 스위치 컷아웃 수 = 왼쪽 30(+스테빌라이저), 오른쪽 43(±1). 최상단 줄 없음.
3. 플레이트·바디 외곽 XY bbox가 PCB 외곽과 동일(±0.05mm).
4. 나사홀 4개가 PCB 외곽 내부 모서리에 존재, M3 사양 유지.
5. PCB 참조 솔리드 상면 Z = +4 − `MX_PLATE_TO_PCB`.
6. FCStd 재생성 후 파트 색상 유지, 좌/우 분리 표시 유지.
7. STL 6종 재export.
